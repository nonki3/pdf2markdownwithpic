# pdf2md 仕様書

| 項目 | 内容 |
| --- | --- |
| 対象プログラム | `pdf2md.py` |
| 目的 | テキスト PDF を、画像を含む Markdown ファイルに変換する |
| 実行環境 | Python 3.10 以上（3.13 で動作確認）／ Windows・macOS・Linux |
| 依存ライブラリ | PyMuPDF 1.24 以上（`import pymupdf`） |
| 最終更新 | 2026-11-23 |

---

## 1. 概要

PDF から本文テキスト・見出し・画像・リンクを取り出し、次の構成の Markdown を生成する。

```
<出力先フォルダ>/
├── <名前>.md            … 本文
└── <名前>_images/       … 画像
    ├── figure-1.jpeg
    ├── figure-2.png
    └── ...
```

Markdown からの画像参照は相対パス（`<名前>_images/figure-N.拡張子`）で、フォルダごと移動してもリンクは切れない。

### 1.1 対象とする PDF

- 文字情報を持つ PDF（Word・InDesign・電子書籍などから出力したもの）
- 1 段組みの横書きレイアウト
- 日本語・英語、または両方が混ざった文書

### 1.2 対象外

| 対象外 | 理由・挙動 |
| --- | --- |
| スキャン PDF（文字が画像） | OCR しないため、ページが画像として出力される |
| 多段組み | 上から順に読むので、段をまたいで読み順が混ざることがある |
| 縦書き | 行の判定が横書き前提 |
| 表の構造化 | 表は行ごとのテキストになる（Markdown の表にはしない） |
| 数式 | テキストとして取れる範囲だけ出力する |
| パスワード付き PDF | 開けないためエラーになる |

---

## 2. 入出力仕様

### 2.1 入力

- PDF ファイル 1 つ（コマンドライン引数で指定）

### 2.2 出力ファイル名の決まり方

| `-o` の指定 | 出力される .md |
| --- | --- |
| 省略 | PDF と同じフォルダの `<PDF名>.md` |
| `.md` で終わるパス | そのパス |
| 拡張子のないパス／既存フォルダ | `<そのフォルダ>/<PDF名>.md` |
| `.md` 以外の拡張子 | 拡張子を `.md` に変えたパス |

- 画像フォルダは `.md` と同じ場所の `<mdの名前>_images/` になる。
- 出力先フォルダがなければ作る。
- 同じ名前のファイルがあれば**上書き**する（画像フォルダ内の古いファイルは消さない）。
- 画像が 1 枚もなければ、空の画像フォルダは消す。

### 2.3 Markdown の形式

| 要素 | 出力形式 | 例 |
| --- | --- | --- |
| 見出し | ATX 形式 `#`〜`######` | `## 現実的な本` |
| 段落 | 1 段落 = 1 行、段落の間は空行 | |
| 画像 | `![代替テキスト](相対パス)` | `![図2](book_images/figure-2.jpeg)` |
| 空白や括弧を含むパス | `<>` で囲む | `![図1](<my book_images/figure-1.png>)` |
| PDF 内リンク | 見出しアンカーへのリンク | `[はじめに](#はじめに)` |
| 外部リンク | URL へのリンク | `[公式サイト](https://example.com)` |
| 上付き文字 | HTML の `<sup>` | `Ｒ<sup>2</sup>` |
| 目次（`--toc` のとき） | 先頭に `## 目次` と入れ子の箇条書き | `- [第１章](#第１章-パラドックス)` |

- 文字コードは UTF-8（BOM なし）、改行は LF。ファイルの最後に改行を 1 つ付ける。
- 行頭の `#` や `>` が見出し・引用と解釈されないよう、本文ではバックスラッシュでエスケープする。

---

## 3. 処理の流れ

```
PDF を開く
  │
  ├─ ① 全ページから行を取り出す（テキスト・位置・フォントサイズ・リンク）
  ├─ ② 文書全体の統計を取る（本文サイズ・左右の余白）
  ├─ ③ 行ごとに右端を推定する
  ├─ ④ ヘッダー・フッター・ページ番号を見つける
  ├─ ⑤ 見出しレベルを決める（フォントサイズ or しおり）
  │
  ├─ ページごとに:
  │    ├─ ⑥ 画像を取り出して保存する
  │    ├─ 行と画像を上から順に並べる
  │    └─ ⑦ 見出し・段落・画像を Markdown ブロックにする
  │
  ├─ ⑧ 見出しアンカーを作り、PDF 内リンクをアンカーに置き換える
  ├─ ⑨（--toc）目次を先頭に追加する
  └─ .md を書き出す
```

---

## 4. 処理の詳細

以下の数値は `pdf2md.py` に書かれている判定基準。単位はポイント（pt、1/72 インチ）。`size` はその行のフォントサイズ。

### 4.1 行の取り出し（①）

- PyMuPDF の `page.get_text("dict", sort=True)` で、行（line）単位にテキストと位置（bbox）を取る。
- 行のフォントサイズ = 行内の文字があるスパンのうち最大のサイズ（上付き文字は除く）。小数第 1 位に丸める。
- 上付き文字（フラグ bit0）は `<sup>…</sup>` にする。
- リンク: リンク範囲と面積の 50% 以上重なるスパンをリンク文字列にする。
  - PDF 内リンク（`LINK_GOTO`）は、リンク先のページと y 座標を一時的な目印として持っておき、⑧ でアンカーに置き換える。
  - 外部リンク（`LINK_URI`）は URL をそのまま使う。
- 行頭が半角または全角スペースなら「字下げあり」とする。

### 4.2 スペースの整理

`--keep-spaces` を付けない場合、**半角の英数字・記号の直後で和文の直前にある半角スペース**を消す。

| 変換前 | 変換後 |
| --- | --- |
| `2020 年` | `2020年` |
| `ROR が０％` | `RORが０％` |
| `平均利益 3.76ドル` | （和文→英数字の向きなので消さない） |

和文の後・英数字の前にあるスペースは、表のような「項目名 値」の区切りであることが多いので残す。

### 4.3 文書全体の統計（②）

| 値 | 求め方 |
| --- | --- |
| 本文サイズ | 文字数で重み付けしたとき、いちばん多く使われているフォントサイズ |
| 全体の右端／左端 | 本文サイズで 8 文字以上の行について、行末／行頭の x 座標の最頻値 |
| ページの右端 | 本文行が 3 行以上あるページで、2 行以上がそろう最も右の x 座標。全体の右端から `本文サイズ × 3` 以上ずれていたら使わない（短い行ばかりのページ対策） |
| ページの左端 | そのページの本文行の行頭 x 座標の最小値 |

### 4.4 行ごとの右端（③）

同じページの中でも文字組みの幅が変わる PDF に対応するため、前後 3 行（同じフォントサイズで、右端近くまで伸びている行）の行末 x 座標の**中央値**を、その行の右端とする。該当する行がなければページの右端を使う。

### 4.5 ヘッダー・フッター・ページ番号（④）

ページの上 10% または下 10% にある行が対象。

- **ページ番号**: 数字 1〜4 桁（前後にハイフンやダッシュがあってもよい）、またはローマ数字だけの行。見つけたら必ず消す。
- **ヘッダー・フッター**: 数字を `#` に置き換えた文字列、y 座標（5pt 単位）、上下どちらにあるか、の 3 つが同じ行が `max(3, 総ページ数 × 30%)` ページ以上に出てきたら消す。

### 4.6 見出しの判定（⑤）

#### フォントサイズで決める（通常）

1. `本文サイズ × 1.1` 以上で、120 文字以下の行のフォントサイズを集める。
2. 大きい順に並べ、差が 0.6pt 未満のサイズは同じグループにまとめる。
3. 大きいグループから順に `#`、`##`、`###`…を割り当てる（`--max-heading-level` まで。それより小さいサイズは本文扱い）。

例（『システムトレード 基本と原則 実践編』）: 本文 12pt ／ 24pt → `#`、17pt → `##`、13.6pt → `###`

#### しおり（アウトライン）で決める

| `--outline` | 挙動 |
| --- | --- |
| `auto`（既定） | フォントサイズで見出しが 1 つも見つからず、しおりがあるときだけしおりを使う |
| `always` | しおりだけを使う |
| `never` | しおりを使わない |

しおりを使う場合、各ページの行の文字列（空白を除く）がそのページのしおりタイトルと同じか、タイトルの先頭部分（4 文字以上）と一致すれば、しおりの階層を見出しレベルにする。

#### 複数行の見出し

前の行が見出しで、次の条件を**すべて**満たすときは 1 つの見出しにつなげる（フォントサイズ判定のときだけ）。

- 同じページで、フォントサイズの差が 0.6pt 未満
- 行間が `size × 0.8` 未満
- 前の行が右端近く（`右端 − size × 2` 以上）まで伸びている＝折り返している

### 4.7 段落の組み立て（⑦）

行を上から順に見て、前の段落につなげるか、新しい段落にするかを決める。

#### 新しい段落にする条件（どれか 1 つでも当てはまれば）

| # | 条件 |
| --- | --- |
| 1 | 空行（空白だけの行） |
| 2 | 見出しや画像の前後 |
| 3 | 前の行とのフォントサイズの差が 0.6pt 以上 |
| 4 | 箇条書きの記号で始まる: `●○◎◆◇■□▲△▼▽•※★☆➢►▶` |
| 5 | 番号付きの項目で始まる: `1.` `１．` `2)` `３）` など（`3.2％` のような小数は除く） |
| 6 | 行頭が字下げされている（スペースで始まる、または左端から `size × 0.8` 以上右にある） |
| 7 | `・ - － * ＊` で始まり、段落の 1 行目も同じ記号で始まっている（箇条書きの続き）、または前の行が折り返しでない |
| 8 | 前の行か今の行が、行全体リンクになっている（目次の項目） |
| 9 | 前の行が右寄せ・中央寄せ（行頭が左端から `size × 2.5` 以上右にある） |
| 10 | 同じページで、前の行との間が `size × 0.9` より空いている |
| 11 | 前の行が折り返しではない（下記） |

例外: 段落の 1 行目が箇条書き・番号付きで、今の行の行頭が 1 行目の行頭から `size × 3` 以内なら、ぶら下げインデントとみなして同じ段落にする（条件 6 の例外）。

#### 折り返しかどうかの判定

前の行の右側の余白（`行の右端 − 前の行の行末`）に、次の行の最初の文字・単語が入らなければ、折り返しとみなす。

- 次の行が英数字で始まる場合: 単語の幅 ≒ `文字数 × size × 0.6`
- それ以外: 単語の幅 ≒ `size`（全角 1 文字）
- 「余白 < 単語の幅 + size × 0.5」なら折り返し
- ただし、前の行が文末（`。．！？!?`、後ろに閉じ括弧があってもよい）で終わり、余白が `size × 0.9` 以上あれば、段落の終わりとする

ページの最後の行が折り返しなら、次のページの最初の行につなげる（ページをまたぐ段落）。

#### 行のつなぎ方

| 前の行の終わり／次の行の始まり | つなぎ方 |
| --- | --- |
| 和文が含まれる | そのままつなぐ |
| 英数字同士 | 半角スペースを 1 つ入れる |
| 英単語の途中のハイフン（`inter-` + `national`） | ハイフンを消してつなぐ |

### 4.8 画像（⑥）

#### 取り出す画像

`page.get_image_info(xrefs=True)` でページに描かれている画像を取り、次のものは除く。

- ページ内に見えている部分の幅か高さが `--min-image-size`（既定 24pt）未満
- 5 ページ以上ある文書で、`max(3, 総ページ数 × 30%)` を超えるページに出てくる画像（ロゴや飾りとみなす）
- 同じページで 2 回目以降に出てくる同じ画像

#### 保存形式

| 元の画像 | 保存形式 |
| --- | --- |
| JPEG（グレー／RGB、透明部分なし） | 元のデータをそのまま `.jpeg` で保存（再圧縮しない） |
| PNG（グレー／RGB、透明部分なし） | 元のデータをそのまま `.png` で保存 |
| 透明部分あり（SMask）・CMYK・JPEG2000・JBIG2 など | RGB（透明部分があれば合成）に変換して `.png` で保存 |
| 取り出しに失敗したもの・インライン画像 | ページの該当部分を `--dpi` でレンダリングして `.png` で保存 |

#### 番号と代替テキスト

- 1 ページ目から順に、各ページの中では上から下・左から右の順で `figure-1`、`figure-2`…と番号を振る。
- 一度保存した画像が別のページに出てきたら、同じファイルを参照する（番号は増やさない）。
- 代替テキスト: 1 枚目の画像が 1 ページ目にあれば `--cover-alt`（既定「表紙」）、それ以外は `--figure-alt`（既定 `図{n}`、`{n}` は番号）。

#### ベクター図（`--vector-figures`）

- `page.cluster_drawings()` で線や塗りがまとまっている範囲を見つける。
- 幅・高さが `max(--min-image-size, 40)` pt 以上の範囲を対象にする。ページ全体を囲む枠（ページの 95% 以上）と、埋め込み画像と 50% 以上重なる範囲は除く。
- 範囲の周りに 2pt の余白を付け、`--dpi` で PNG にレンダリングする。
- 図の範囲内（行の面積の 80% 以上）にある文字は図に含まれているので、本文からは除く。

### 4.9 アンカーとリンク（⑧）

#### アンカーの作り方（GitHub・VS Code と同じ規則）

1. HTML タグとリンクの書式を取り除く
2. 前後の空白を取り、英字を小文字にする
3. 文字・数字・`_`・`-`・半角スペース以外の文字（`、` `（` `）` `――` など）を消す
4. 半角スペースを `-` にする
5. 同じアンカーが 2 回目以降に出てきたら `-1`、`-2`…を付ける

| 見出し | アンカー |
| --- | --- |
| `意見でも俗説でもなく、エビデンス` | `#意見でも俗説でもなくエビデンス` |
| `第１章 パラドックス` | `#第１章-パラドックス` |
| `まとめ`（2 回目） | `#まとめ-1` |

#### PDF 内リンクの置き換え

リンク先（ページ、y 座標）から、次の順でアンカーを決める。

1. そのページで、y 座標より下（10pt の誤差まで許す）にある最初の見出し
2. そのページの最後の見出し
3. それより前のページで最後の見出し
4. どれもなければリンクを外して文字だけにする

### 4.10 目次（⑨、`--toc`）

- 先頭に `## 目次` を入れ、すべての見出しをリンク付きの箇条書きで並べる。
- いちばん上のレベルを基準に、レベルが 1 つ深くなるごとに 2 スペース字下げする。

## 5. コマンドラインの仕様

```
python pdf2md.py PDF [-o OUTPUT] [--max-heading-level {1..6}]
                     [--min-image-size PT] [--vector-figures] [--dpi DPI]
                     [--toc] [--outline {auto,always,never}]
                     [--cover-alt TEXT] [--figure-alt FMT]
                     [--keep-spaces] [-q]
```

| 引数 | 型 | 既定値 | 説明 |
| --- | --- | --- | --- |
| `PDF` | パス | （必須） | 入力 PDF |
| `-o`, `--output` | パス | PDF と同じ場所 | 出力 .md（2.2 を参照） |
| `--max-heading-level` | 1〜6 | 3 | 見出しにする最大レベル |
| `--min-image-size` | 数値（pt） | 24 | これより小さい画像は無視する |
| `--vector-figures` | フラグ | オフ | ベクター図も画像として切り出す |
| `--dpi` | 整数 | 150 | レンダリングする画像の解像度 |
| `--toc` | フラグ | オフ | 先頭に目次を付ける |
| `--outline` | auto / always / never | auto | しおりの使い方（4.6 を参照） |
| `--cover-alt` | 文字列 | `表紙` | 表紙画像の代替テキスト。空文字 `""` で使わない |
| `--figure-alt` | 文字列 | `図{n}` | 画像の代替テキストの書式 |
| `--keep-spaces` | フラグ | オフ | 4.2 のスペース整理をしない |
| `-q`, `--quiet` | フラグ | オフ | 進み具合を表示しない |

### 5.1 標準エラー出力

`-q` を付けなければ、次の内容を標準エラー出力に表示する（標準出力には何も出さない）。

```
<PDF名>: <ページ数> ページ
本文サイズ 12.0pt / 見出し: 24.0pt→#, 17.0pt→##, 13.6pt→###
  50/526 ページ処理済み          … 50 ページごと
完了: <出力パス> (見出し 333 件, 画像 161 枚)
```

画像の取り出しに失敗したときは `[warn] p.<ページ> xref=<番号>: <理由>; 領域をレンダリングします` と表示して処理を続ける。

### 5.2 終了コード

| コード | 意味 |
| --- | --- |
| 0 | 成功 |
| 2 | 引数の誤り、または入力ファイルがない |
| 1 | その他のエラー（PDF が壊れている、書き込めないなど。Python の例外メッセージを表示） |

## 6. Python API

```python
from pathlib import Path
from pdf2md import PdfToMarkdown

PdfToMarkdown(
    Path("book.pdf"),
    Path("out/book.md"),
    max_heading_level=3,     # --max-heading-level
    min_image_size=24.0,     # --min-image-size
    vector_figures=False,    # --vector-figures
    dpi=150,                 # --dpi
    toc=False,               # --toc
    cover_alt="表紙",        # --cover-alt
    figure_alt="図{n}",      # --figure-alt
    use_outline="auto",      # --outline
    keep_spaces=False,       # --keep-spaces
    verbose=True,            # False で -q と同じ
).convert()                  # 戻り値: 書き出した .md の Path
```

| 名前 | 種類 | 内容 |
| --- | --- | --- |
| `PdfToMarkdown` | クラス | 変換を行う本体 |
| `PdfToMarkdown.convert()` | メソッド | 変換して .md を書き出す |
| `PdfToMarkdown.headings` | 属性 | `convert()` 後の見出しの一覧（`Heading`: ページ、y 座標、レベル、文字列、アンカー） |
| `slugify(text)` | 関数 | 見出しの文字列からアンカーを作る |
| `main(argv)` | 関数 | コマンドラインの入口（引数のリストを渡せる） |

1 つのインスタンスで `convert()` を呼べるのは 1 回だけ（画像の番号などの状態を持つため）。

## 8. 精度の確認結果

『システムトレード 基本と原則 実践編』を、別の方法で作られた参考 Markdown と比べた結果。

| 項目 | 結果 |
| --- | --- |
| 見出しの数 | 333（参考 332。違いは「目次」を見出しにしたかどうか） |
| 画像の数と並び順 | 161 枚、順番は完全に一致 |
| 本文の行の一致率 | 95%（3716 / 3914 行） |

一致しなかった行のほとんどは段落の区切りの違いで、PDF の見た目だけでは判断できないもの（4.7 の制限）。

## 9. 制限事項と既知の問題

1. **段落の終わりが右端ちょうどの場合**: 最後の行が右端まで埋まっている段落は、次の段落とつながることがある。
2. **文字組みの幅が不ぞろいな PDF**: 本文の途中で右端の位置が変わると、段落の区切りを間違えることがある。
3. **本文より大きい文字の強調**: 見出しでない大きな文字（献辞、引用など）も見出しになることがある。
4. **太字・斜体**: 出力しない（日本語フォントでは判定が不安定なため）。
5. **脚注**: 本文として、出てきた位置に出力する。
6. **表**: 1 行ずつのテキストになる。
7. **ベクター図**: 罫線だけの表や下線も図として切り出されることがある。そのため既定ではオフにしている。
8. **画像フォルダの古いファイル**: 上書きのときに消さないので、前回のほうが画像が多いと古いファイルが残る。
