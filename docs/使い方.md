# pdf2md 使い方ガイド

PDF を画像付きの Markdown に変換する `pdf2md.py` の使い方を、準備から困ったときの対処まで説明します。
動作の詳しい決まりは [仕様書](仕様書.md) を見てください。

---

## 1. 準備（初回だけ）

### 1.1 Python があるか確認する

PowerShell で次を実行します。

```powershell
py --version
```

`Python 3.10` 以上が表示されれば OK です。表示されなければ [python.org](https://www.python.org/downloads/) からインストールしてください。

> **メモ**: Windows では `python` と打つと Microsoft Store が開くことがあります。その場合は `py` を使ってください。

### 1.2 仮想環境を作ってライブラリを入れる

プロジェクトのフォルダで実行します。

```powershell
cd D:\DevProjects\pdf2markdownwithpic
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

これで `.venv` フォルダに PyMuPDF が入ります。以降のコマンドは `.\.venv\Scripts\python.exe` で実行します。

> **毎回のパス入力を省きたいとき**: `.\.venv\Scripts\Activate.ps1` を実行すると、そのウィンドウでは `python pdf2md.py ...` だけで動きます。
> 「スクリプトの実行が無効」と言われたら、先に `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` を実行してください。

macOS / Linux の場合:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

## 2. 基本の使い方

### 2.1 いちばん簡単な変換

```powershell
.\.venv\Scripts\python.exe pdf2md.py "D:\Books\本.pdf"
```

PDF と同じフォルダに次のものができます。

```
D:\Books\
├── 本.pdf
├── 本.md
└── 本_images\
    ├── figure-1.jpeg
    ├── figure-2.jpeg
    └── ...
```

実行中はこのように表示されます。

```
本.pdf: 526 ページ
本文サイズ 12.0pt / 見出し: 24.0pt→#, 17.0pt→##, 13.6pt→###
  50/526 ページ処理済み
  ...
完了: D:\Books\本.md (見出し 333 件, 画像 161 枚)
```

2 行目では、どのフォントサイズを見出しにしたかがわかります。結果がおかしいときはまずここを確認してください（→ [5. うまくいかないとき](#5-うまくいかないとき)）。

> **ファイル名に空白があるとき**は、パスを `"..."` で囲んでください。

### 2.2 出力先を指定する

```powershell
# ファイル名を指定
.\.venv\Scripts\python.exe pdf2md.py 本.pdf -o D:\docs\本_実践編.md

# フォルダだけ指定（中に 本.md ができる）
.\.venv\Scripts\python.exe pdf2md.py 本.pdf -o D:\docs
```

画像フォルダの名前は `.md` の名前に合わせて決まります（`本_実践編.md` → `本_実践編_images\`）。

### 2.3 できた Markdown を見る

- **VS Code**: `.md` を開いて `Ctrl+Shift+V`（プレビュー）。画像も目次のリンクもそのまま使えます。
- **GitHub**: `.md` と `_images` フォルダを一緒にコミットすれば、そのまま表示されます。
- **Obsidian など**: `.md` と `_images` フォルダを同じ場所に置けば表示されます。

> `.md` だけを別の場所にコピーすると画像が表示されません。**必ず `_images` フォルダと一緒に**移動してください。

## 3. 用途別の使い方

### 3.1 先頭に目次を付けたい

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --toc
```

先頭にこのような目次が付きます。クリックするとその見出しに移動します。

```markdown
## 目次

- [はじめに](#はじめに)
  - [現実的な本](#現実的な本)
  - [シリーズ本として](#シリーズ本として)
- [第１章 パラドックス](#第１章-パラドックス)
```

> PDF に目次ページがある場合、その目次もリンク付きで本文に出力されます。`--toc` を付けると目次が 2 つになるので、どちらかを選んでください。

### 3.2 グラフや図が抜けてしまう

PDF の図には「画像として埋め込まれたもの」と「線や塗りで描かれたもの（ベクター図）」があります。通常は前者しか取り出しません。グラフが抜けている場合は次を試してください。

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --vector-figures
```

- ベクター図を PNG 画像にして、本文の位置に入れます。
- 図の中の文字（軸の目盛りなど）は画像に含まれるので、本文からは消えます。
- 罫線だけの表や飾りの線も図として切り出されることがあります。結果を見て、不要なら付けずに実行し直してください。

もっときれいな画像にしたいときは解像度を上げます（ファイルは大きくなります）。

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --vector-figures --dpi 300
```

### 3.3 小さなアイコンやロゴが大量に出る

小さい画像を無視する基準を上げます（単位は pt。1pt ≒ 0.35mm）。

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --min-image-size 60
```

なお、全体の 30% を超えるページに出てくる同じ画像（ロゴなど）は最初から除外されます。

### 3.4 見出しのレベルを変えたい

```powershell
# #### まで見出しにする
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --max-heading-level 4

# # と ## だけにする（それより小さい見出しは本文扱い）
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --max-heading-level 2
```

### 3.5 PDF のしおり（ブックマーク）で見出しを決めたい

フォントサイズで見出しをうまく判定できない PDF でも、しおりがあればそれを使えます。

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --outline always
```

| 指定 | 使う場面 |
| --- | --- |
| `auto`（既定） | 通常はこれ。フォントサイズで判定できないときだけしおりを使う |
| `always` | しおりが細かく作られていて、そのとおりの見出しにしたいとき |
| `never` | しおりの内容が本文と合っていないとき |

> しおりは「章」だけのことが多く、`always` にすると節の見出しがなくなることがあります。2 行目の表示（`見出し: PDFのしおり`）と結果を見て選んでください。

### 3.6 画像の代替テキストを変えたい

```powershell
# 「Figure 1」「Figure 2」…にする
.\.venv\Scripts\python.exe pdf2md.py report.pdf --figure-alt "Figure {n}"

# 1 枚目を「表紙」にしない
.\.venv\Scripts\python.exe pdf2md.py report.pdf --cover-alt ""
```

`{n}` の部分に画像の番号が入ります。

### 3.7 英数字と和文の間のスペースを残したい

既定では `2020 年` → `2020年` のように、PDF が入れた余計なスペースを消します。元のまま残したい場合は次のようにします。

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf --keep-spaces
```

### 3.8 進み具合を表示しない

```powershell
.\.venv\Scripts\python.exe pdf2md.py 本.pdf -q
```

## 4. まとめて変換する

### 4.1 フォルダ内の PDF をすべて変換（PowerShell）

```powershell
Get-ChildItem D:\Books\*.pdf | ForEach-Object {
    .\.venv\Scripts\python.exe pdf2md.py $_.FullName -o D:\Markdown -q
    Write-Host "変換: $($_.Name)"
}
```

`D:\Markdown` に `<PDF名>.md` と `<PDF名>_images\` が PDF ごとにできます。

### 4.2 bash の場合

```bash
for f in ~/Books/*.pdf; do
  .venv/bin/python pdf2md.py "$f" -o ~/Markdown -q && echo "変換: $f"
done
```

### 4.3 Python から使う

```python
from pathlib import Path
from pdf2md import PdfToMarkdown

conv = PdfToMarkdown(
    Path("D:/Books/本.pdf"),
    Path("D:/Markdown/本.md"),
    toc=True,
    vector_figures=True,
    verbose=False,
)
md_file = conv.convert()

print(md_file)                      # D:\Markdown\本.md
for h in conv.headings[:5]:         # 見つかった見出し
    print(h.level, h.text, h.slug)
```

引数はコマンドラインのオプションと同じです（[仕様書 6 章](仕様書.md#6-python-api)）。1 つの `PdfToMarkdown` で変換できるのは 1 回だけなので、PDF ごとに作り直してください。

## 5. うまくいかないとき

### 5.1 症状と対処の早見表

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| 本文がほとんど出ず、ページの画像だけになる | スキャン PDF（文字が画像） | OCR ソフト（Adobe Acrobat、OCRmyPDF など）で文字を付けてから変換する |
| 見出しが 1 つもない | 見出しと本文の文字の大きさが同じ | しおりがあれば `--outline always`。なければ変換後に手で `#` を付ける |
| 大きな文字の段落（献辞・引用など）が見出しになる | 本文より大きい文字は見出しと判定される | `--max-heading-level` を下げる、または手で直す |
| 見出しのレベルがずれる（章が `##` になる等） | 表紙や扉のさらに大きい文字が `#` になった | 変換後に手で直す。しおりがあれば `--outline always` も試す |
| グラフや図が抜けている | ベクター図 | `--vector-figures` |
| 不要な線や枠が図として出る | `--vector-figures` の副作用 | `--vector-figures` を外す、`--min-image-size` を上げる |
| 小さいアイコンが大量に出る | 小さい画像も取り出している | `--min-image-size 60` など |
| 2 つの段落が 1 つにつながる | 段落の最後の行が右端まで埋まっている | 手で改行を入れる（PDF の見た目では区別できないため） |
| 1 つの段落が途中で切れる | 行の右端が本文の途中でそろっていない | 手でつなげる |
| 2 段組みで文章が混ざる | 1 段組み前提 | 未対応。段ごとにページを切り出した PDF を作れば変換できる |
| 表が崩れる | 表は 1 行ずつのテキストになる | 手で Markdown の表に直す |
| ページ番号やヘッダーが残る | 位置が上下 10% より内側、または出てくるページが少ない | 手で消す |
| 画像が表示されない | `.md` だけを移動した／フォルダ名を変えた | `.md` と `<名前>_images\` を同じ場所に置く |
| 古い画像がフォルダに残っている | 上書きのとき古い画像は消さない | 変換前に `<名前>_images\` フォルダを消す |

### 5.2 エラーメッセージ

| メッセージ | 意味と対処 |
| --- | --- |
| `ファイルが見つかりません: ...` | パスの間違い。空白を含むなら `"..."` で囲む |
| `FileDataError: Failed to open file` | PDF が壊れているか、PDF ではない |
| `ModuleNotFoundError: No module named 'pymupdf'` | 仮想環境の Python で実行していない。`.\.venv\Scripts\python.exe` を使うか、1.2 をやり直す |
| `PermissionError` | 出力先の `.md` を別のアプリで開いている、または書き込めない場所 |
| `[warn] p.12 xref=345: ...; 領域をレンダリングします` | 画像を元の形式で取り出せなかったため、ページから切り出して保存した（処理は続く） |
| `invalid choice` | オプションの値の間違い（例: `--outline` は `auto` `always` `never` のどれか） |

### 5.3 PowerShell で文字化けする

表示が `�` になる場合は、出力ファイル自体は正しい UTF-8 です。表示だけが崩れているので、次を実行してから再度表示してください。

```powershell
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
```

## 6. 変換後のチェックリスト

変換が終わったら、次の点を確認すると手直しが早く済みます。

- [ ] 2 行目の `見出し:` の割り当てが、PDF の章・節の文字の大きさと合っているか
- [ ] VS Code のアウトライン表示（エクスプローラーの「アウトライン」）で見出しの階層が正しいか
- [ ] 画像の枚数（`完了:` の行）が PDF の図の数とだいたい合っているか
- [ ] 目次のリンクをいくつかクリックして、正しい見出しに飛ぶか
- [ ] 箇条書き（●、・）が 1 項目ずつ分かれているか
- [ ] 表のページ（あれば）を手で直したか
