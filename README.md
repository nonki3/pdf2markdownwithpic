# pdf2markdownwithpic

PDF を **画像付きの Markdown** に変換する Python スクリプトです。

```
book.md
book_images/
    figure-1.jpeg
    figure-2.jpeg
    ...
```

Markdown 内では画像が本文中の元の位置に `![図2](book_images/figure-2.jpeg)` として挿入されます。

## ドキュメント

- [使い方ガイド](docs/使い方.md): 準備、用途別の使い方、まとめて変換する方法、困ったときの対処
- [仕様書](docs/仕様書.md): 入出力の形式、見出し・段落・画像の判定基準、コマンドラインと Python API の仕様、制限事項

## セットアップ

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 使い方

```powershell
# PDF と同じフォルダに <PDF名>.md と <PDF名>_images/ を出力
.\.venv\Scripts\python.exe pdf2md.py "D:\path\to\book.pdf"

# 出力先を指定 + 先頭に目次を生成
.\.venv\Scripts\python.exe pdf2md.py book.pdf -o docs\book.md --toc
```

| オプション | 説明 |
| --- | --- |
| `-o, --output` | 出力する .md ファイル（フォルダを指定すると `<PDF名>.md`） |
| `--toc` | 見出しから目次（リンク付き）を生成して先頭に追加 |
| `--max-heading-level N` | 見出しとして扱う最大レベル（既定 3 = `###` まで） |
| `--outline auto/always/never` | PDF のしおりを見出し判定に使うか（既定 auto: フォントサイズで判定できない時だけ使用） |
| `--vector-figures` | ベクターで描かれたグラフや図も PNG として切り出す |
| `--dpi N` | 図をレンダリングするときの解像度（既定 150） |
| `--min-image-size PT` | これより小さい画像は無視（既定 24pt） |
| `--cover-alt TEXT` | 1 ページ目の最初の画像の代替テキスト（既定「表紙」、空文字で無効） |
| `--figure-alt FMT` | 画像の代替テキスト書式（既定 `図{n}`） |
| `--keep-spaces` | `2020 年` のように英数字と和文の間にある半角スペースを残す |
| `-q, --quiet` | 進捗を表示しない |

## 変換の仕組み

- **見出し**: 本文で最も多く使われているフォントサイズを本文サイズとし、それより大きいサイズを大きい順に `#`, `##`, `###` に割り当てます。
- **段落**: 行が右端まで達していれば次の行へ続く（折り返し）とみなして結合します。行が短い、文末（。！？）で余白がある、空行・字下げ・箇条書き記号（●、・、１．など）がある場合は段落を区切ります。ページをまたぐ段落も結合します。
- **画像**: 埋め込み画像は再圧縮せず元のデータのまま保存します（JPEG→`.jpeg`）。透過マスク付き・CMYK・JPEG2000 などは PNG に変換します。同じ画像の再利用は 1 ファイルにまとめ、多数のページに出るロゴ等は除外します。
- **リンク**: PDF 内リンク（目次など）はリンク先ページの見出しへのアンカーリンク（`[第１章](#第１章-パラドックス)`）に、外部 URL はそのままリンクに変換します。アンカーは GitHub / VS Code の規則と同じです。
- **ヘッダー/フッター**: ページ上下の余白に繰り返し出る文字列とページ番号を除去します。
- 上付き文字は `<sup>2</sup>` として出力します。

## 制限事項

- 1 段組みのレイアウトを想定しています（多段組みは読み順が崩れることがあります）。
- 表は Markdown の表にはならず、行ごとのテキストとして出力されます。
- スキャンした PDF（文字が画像になっているもの）は OCR しないため、ページ画像として出力されます。
- 段落の切れ目はレイアウトから推定しているため、右端ちょうどで終わる段落末尾は次の段落と結合されることがあります。
